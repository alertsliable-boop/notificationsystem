## 🎯 Color Classes

```css
bg-signal-blue     → iOS Blue (#007aff)
bg-ink-black       → Headings (#000000)

bg-smoke           → Muted text (#636363)
bg-paper-white     → Card surfaces (#ffffff)
bg-ash-mist        → Canvas (#f7f7f7)
```
